# Primer markdown.

- ¿Qué es un programa informático?

- Es un sistema que codifica la serie de pasos, isntrucciones o algoritmo, necesario para resolver un problema u obtener un resultado de acuerdo al input que se le ha dado al sistema. En informática es el resultado de una serie de ordenes que se le da a un ordenador para poder interactuar con él y obtener determinadas respuestas.

- Diferencia entre código fuente, código objeto y código ejecutable. Código fuente: es un programa cuyos pasos están escritos en lenguaje humano Código objeto: es la compilación de la traducción del código fuente a lenguaje de máquina Código Ejecutable: Es el resultado de la traducción del código fuente para que pueda ser "leído" por la máquina

- Etapas del desarrollo del software. Planificación Análisis Diseño Programación Pruebas Implementación Mantenimiento	 Documentación
